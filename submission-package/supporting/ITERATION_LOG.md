# 主要版本迭代

本提交包入库后 GitHub 共有 16 次提交。以下只列对产品判断有明显影响的阶段，不把每个小修复包装成独立版本。

| 阶段 | 核心变化 | 为什么改 |
|---|---|---|
| 1. 证据优先原型 | 建立 Source → Evidence → Claim → 训练的基础闭环 | 避免模型把无来源内容写成学校事实 |
| 2. 三类训练 | 补齐机试、专业面试、项目追问及会话隔离 | 验证从资料到训练的纵向闭环 |
| 3. 项目化数据模型 | 引入学校项目、申请目标、资料、题单版本、简历和导师档案 | 解决北大、清华等目标资料串用 |
| 4. 真实外部服务 | 接入 Tavily 搜索和 DeepSeek 生成 | 从演示 fixture 过渡到真实研究链路 |
| 5. 界面重构 | 改为 ChatGPT 式项目侧栏和三个独立页面，删除聊天输入框与重复入口 | 用户反馈原界面拥挤、不知道从哪里开始 |
| 6. 资料质量升级 | 从普通规则清洗升级为“规则预筛 + DeepSeek 二次复核” | 联网资料数量增加后，题单仍大量无来源 |
| 7. 结构化输出修复 | 严格 JSON Schema，只读取 DeepSeek Responses 的 `output_text` | 旧代码误把推理文本当成 JSON，导致优质资料被错误过滤 |
| 8. 项目管理补齐 | 新增三点菜单、置顶/取消置顶和可靠删除 | 让多个学校项目的管理更符合用户熟悉的交互 |

完整提交历史：<https://github.com/Sa63R/baoyan-prep/commits/main>
