# AI 工具与开源使用披露

## AI 工具

- **OpenAI Codex**：需求拆解、代码实现、重构、调试、测试、界面验收、Git 提交和提交材料整理。关键产品方向与取舍由提交人持续提出和确认。
- **DeepSeek API**：运行时资料二次筛选、结构化题单生成与一次性代码复盘。模型输出不会被当成真实判题或学校官方事实。
- **Tavily API**：发现公开网页候选来源。搜索摘要只用于发现线索，正文读取与二次复核后才进入资料库。

## 开源参考与依赖

- **zmy15/interview-agent**（MIT）：参考求职者模式的工具栏、工作区组织与输入交互；本项目删除面试官、岗位/JD、认证和原 RAG 后端，并重新实现为保研项目、资料库与三关题单。
- **Morphic**（Apache-2.0）：只用于研究引用交互与依赖组织，没有复制其源文件。
- **shadcn/ui / Base UI**（MIT）：可访问 UI 基础组件。
- **Lucide**（ISC）：界面图标。
- **Next.js、React、Drizzle ORM、better-sqlite3、unpdf**：按各自许可证作为依赖使用。

完整版本、参考 commit、改动路径和许可证副本见仓库 `THIRD_PARTY_NOTICES.md` 与 `licenses/`。

## 原创与隐私边界

- 产品业务逻辑、数据模型、资料筛选策略、三关流程和当前界面是在 AI 辅助下为本项目实现的。
- API Key、`.env.local`、SQLite 数据库、上传文件、简历和用户资料不会进入公开仓库。
- 测试和演示只使用脱敏或虚构数据，不使用真人个人信息。
