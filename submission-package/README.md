# 循证保研提交包

本文件夹按《AI 模拟面试官 · 16 小时项目挑战》的提交要求整理。Demo 视频不在本文件夹内，由提交人录制后单独附上或提供链接。

## 建议提交顺序

1. 先打开 `SUBMISSION_CHECKLIST.md`，处理所有标为“提交前必须完成”的事项。
2. 将 `PRODUCT_MEMO.pdf` 作为正式 Product Memo 附件；`PRODUCT_MEMO.md` 是可继续修改的源稿。
3. 把公网产品地址补入 `LINKS_AND_ACCESS.md` 和 `EMAIL_DRAFT.txt`。
4. 按 `DEMO_RECORDING_GUIDE.md` 录制 3 分钟以内的视频。
5. 需要附加材料时，只选择 `supporting/` 中最有帮助的 2–3 份，不要为了数量全部发送。

## 文件说明

| 文件 | 用途 |
|---|---|
| `SUBMISSION_CHECKLIST.md` | 最终提交清单、当前状态和风险项 |
| `PRODUCT_MEMO.pdf` | 1–2 页正式 Product Memo |
| `PRODUCT_MEMO.md` | Memo 可编辑源稿 |
| `LINKS_AND_ACCESS.md` | 公网产品、GitHub、测试方式与部署限制 |
| `EMAIL_DRAFT.txt` | 发给主办方的邮件正文草稿 |
| `DEMO_RECORDING_GUIDE.md` | 录屏流程与镜头检查，不包含视频文件 |
| `supporting/ARCHITECTURE.md` | 当前版本架构与数据流 |
| `supporting/TEST_REPORT.md` | 已验证、未验证和已知问题 |
| `supporting/ITERATION_LOG.md` | 从通用面试页到三关工作台的主要迭代 |
| `supporting/AI_AND_OPEN_SOURCE_DISCLOSURE.md` | AI 工具与开源参考披露 |
