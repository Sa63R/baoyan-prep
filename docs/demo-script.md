# 三分钟 Demo 脚本

## 0:00–0:25：先展示差异

打开调查档案，直接点击“本批次包含上机测试与综合面试”后的 `[E01]`。右侧展示原始日期、所述年份、适用范围、抓取时间和精确段落。说明：这不是聊天回答，而是能回到原文的结论。

## 0:25–0:55：展示诚实的不确定性

依次指出“2025 年个人回忆”和“2027 年语言/题量/时长未知”。说明旧年经验只决定训练主题，不升级为今年规则；冲突与缺口不会被抹平。

## 0:55–1:35：来源到机试闭环

点击“机试训练”。展示 `generated · 原创` 标签、推荐理由 `[E02]`、完整样例和代码编辑器。输入一段解法并点“AI 代码审查”。强调界面显示“固定演示 · 未调用模型”，记录类型是 `ai_review`，不是 AC；“自报 OJ 已通过”则是 `self_reported`。

## 1:35–2:10：面试不提前泄漏答案

进入“专业面试”，切换试卷模式。提交前看不到回答要点；写一段回答后提交，展示针对实际回答的主要缺口、改进动作和复测题。点击下一轮，展示澄清 → 故障追问 → 工程取舍的三轮路径。

## 2:10–2:40：简历事实与导师证据双绑定

进入“项目追问”。指出左侧是虚构简历原文，右侧是导师研究 `[E03]`，关联强度只写“中等”。先确认职责和指标没有被补写，再回答指标选择问题；展示“尚未提供：误差分桶、延迟、对照实验”，不编造实验。

## 2:40–3:00：资料、安全与持久化

进入“资料与来源”，快速展示 URL、粘贴、文件三入口和受限页面状态。刷新页面后训练记录仍在 SQLite；不同浏览器会话互相隔离。收尾说明：演示数据均为虚构，真实 Tavily/模型配置缺失时明确报错；当前尚未公网部署。
